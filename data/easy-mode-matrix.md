# Oathfilter Easy Mode: which line sits where

Generated by `tools/export-affix-db.mjs` from the code (build 87). Named lines match by their text, so a gear line also covers every line with the same text (Idol lines, `_2h`, `ring_` variants).

Idol tiers exist in the game data, but Easy Mode puts no tier limit on Idol rules (`tier_in_filter` is false for Idol lines in the database).
