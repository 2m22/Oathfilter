      Quick start
      
    
        
     
      • 1. Choose a mode. Easy builds a whole filter from a few picks. Advanced starts from a game preset and lets you edit every rule.
        • 
     
      • 2. Set it up. Easy: set Rupture Level and Tier strictness, then pick what you want to see. Advanced: select a rule, set what it checks and does, and drag rules into order.
        • 
     
      • 3. Test it. Open Drop Test and press Drop 25 or a Quick spawn button. Each sample shows which rule caught it. In Easy Mode it tests the Easy preview.
        • 
     
      • 4. Copy it. Press “Copy filter code” in the bar at the top, then paste the code into the game’s loot filter window.
        • 
    
      
  
      How rules work
      
    
      Order is the most important part of a filter. The game checks the rules from top to bottom. The first rule that matches an item decides, and the rules below it never see that item.
      
    
      The basics
      
    
        
     
      • Up to 40 rules. The counter at the top shows how many you use.
        • 
     
      • No match. An item that no rule matches is shown as normal.
        • 
     
      • On or off. The switch on a rule skips it without deleting it.
        • 
     
      • One line group per rule. To look for two line groups, use two rules.
        • 
    
      
    
      Easy Mode
      
    
        
     
      • Rupture Level. The monster level you farm at, which is also the item drop level. Only affix tiers up to that item level can drop. Any means no tier limit.
        • 
     
      • Tier strictness. For each line you pick, how many of the best droppable tiers still count as good: best tier only, best 2 or best 3. Weaker lines are hidden. Idols are not limited.
        • 
     
      • What I want to see. Each pick keeps its gear lines and the matching Idols, and hides the other Idols. A damage type (Physical, Fire, Cold, Lightning, Poison) or ailment (Bleed, Ignite) narrows Attacks and Spells: with Spells + Cold, Fire and Lightning spell lines are not kept. An item that also has another picked line (for example Spell Damage) stays visible. A line that two picks share is listed once. Choose at least one pick.
        • 
     
      • Preview. Easy Mode shows the result first. Applying it replaces the rules in your Editor (Ctrl+Z brings them back).
        • 
    
      
    
      Never hidden
      
    
       The Drop Test marks them SHOW*.
      
  
      What a rule can check
      
    
      Everything you set on one rule must fit at the same time.
      
    
        
     
      • Rarity. Any, normal, magic, normal and magic, rare, or rare and unique.
        • 
     
      • Item type. Any gear, weapons or one weapon kind, armour slots, rings, amulets, belts, idols, gems, rune bases, core-touched, 4+ sockets or Truesworn.
        • 
     
      • Item level. One step: below 20, 40, 60 or 75, or 60, 75 or 82 and up. MORE adds a from–to range.
        • 
     
      • Line group. One group of affix lines, such as life, resistance, critical, minion or fire damage.
        • 
     
      • Roll quality. Any roll, good roll or top roll.
        • 
     
      • Lines needed. How many matching lines the item needs: 1+, 2+ or 3+.
        • 
    
      
  
      More conditions (the MORE button)
      
    
      All MORE options must fit together with the options above.
      
    
      Item options
      
    
        
     
      • Tier. A tier, and how many lines of that tier or better the item needs.
        • 
     
      • Sockets and levels. Sockets, item level and required level, as from–to ranges.
        • 
     
      • Grade. Base grade (50+, 70+, Truesworn) and top grade.
        • 
     
      • Reds and unsworn. Reds only, chase reds only, and unsworn or not.
        • 
     
      • Runes. Runes up to a chosen tier.
        • 
    
      
    
      Named entries
      
    
        
     
      • Up to four. Name up to four bases, lines or reds in one rule.
        • 
     
      • Any or all. A named line matches when the item has an affix of that line. With several named lines, “Any of them” (default) needs one, “All of them” needs every one.
        • 
    
      
  
      Actions, colours and sounds
      
    
      Actions
      
    
        
     
      • Hide. The item is not shown, except the items under “Never hidden”.
        • 
     
      • Show. The item is shown as normal.
        • 
     
      • Highlight. The item name is drawn in the chosen colour.
        • 
     
      • Highlight + beam. Colour plus a light beam on the ground.
        • 
     
      • Sell. 
        • 
    
      
    
      Look and sound
      
    
        
     
      • Colours. Ember, Jade, Frost, Bone, Gold, Blood, Ash and White.
        • 
     
      • Sounds. Auto (game default), Silent, Chime, Soft, Jewel and Wind.
        • 
    
      
  
      Building a good filter
      
    
      A good order
      
    
        
     
      • 1. Valuable first. Put the most precious rules (high rolls, top tiers, named reds) at the top, with Highlight + beam and their own colour and sound.
        • 
     
      • 2. Then wider highlights. Rules for good but common items, with a plain highlight or no sound.
        • 
     
      • 3. Hide last. Rules that hide junk (low item level, normal or bad magic items) go near the bottom, so they cannot catch something above them.
        • 
    
      
    
      Tips
      
    
        
     
      • Start from a preset. Load Tidy or Strict and change only what you need.
        • 
     
      • Check the order. A broad rule above a narrow one means the narrow one never fires. The rule list warns “May be caught by rule N” when it is sure. “Check rule order” in the Editor also runs sample items through your filter and lists rules that never decide anything.
        • 
     
      • Confirm in the game. Always check the finished filter in the game.
        • 
    
      
  
      Using the Drop Test
      
    
      The Drop Test checks your rules, not drop rates. It makes up sample items across many rarities, bases and tiers, so you can see which rule catches each one and in what order. How often an item really drops is not tested.
      
    
      Controls
      
    
        
     
      • Drop 1 / Drop 25 / Auto-drop. Varied sample items. Reset clears the log and the counters.
        • 
     
      • Easy Mode. While Easy Mode is active, the Drop Test runs the Easy preview (up to 40 rules). A note above the result says so.
        • 
     
      • Quick spawn. Targeted items: White, Magic good or bad, Rare valuable, decent, bad or mid, Unique / Red and Idol. Use them to test a rule that random samples rarely hit.
        • 
     
      • Check a drop screenshot. Paste (Ctrl+V), drop or choose a screenshot of a drop or tooltip. The text is read on your device and you can fix it before checking. The first matching rule is found top to bottom from what the screenshot shows: rarity, type, item level, tiers and lines. Details it cannot show (for example an unexpanded Alt tooltip) are listed as open points.
        • 
     
      • Sliders. “Lines at T1” sets how many T1 lines Rare valuable has (1–6), “Item level” the item level, “Idol size” the idol size (1–4) and “Per click” how many items one press creates.
        • 
    
      
    
      Reading the result
      
    
        
     
      • Counters and bar. How many samples are shown, highlighted, hidden or sold. Hidden and sold samples stay in the log with a dashed border.
        • 
     
      • Ground view and log. The ground view shows what you would see in the game. Each log entry names the rule that caught the item, or says that no rule matched.
        • 
     
      • What the samples are. They use real bases, affixes and uniques from the public API. How they are rolled (mods per item, tiers) only needs to be varied enough to exercise your rules. It is not the game’s roll logic.
        • 
    
      
  
      Import and export
      
    
      Import
      
    
        
     
      • The code. The game’s BOFILTER 1 code, for example BOFILTER:1,…. Copy it in the game’s loot filter window and paste it in the Import tab.
        • 
     
      • MORE options. They follow the ten numbers of a rule as ,3:key=value;key=value. The page reads them and you can change them in the Editor.
        • 
     
      • Unknown fields. 
        • 
    
      
    
      Export
      
    
        
     
      • Game code. “Copy filter code” in the bar at the top copies the code you paste into the game. In Easy Mode it copies the Easy preview, otherwise your active filter.
        • 
     
      • Share. “Share” in the bar at the top makes a short link to your active filter with its rule names. In Easy Mode it first replaces your filter with the Easy Mode rules (Ctrl+Z brings yours back). Whoever opens it sees a preview first and can load it or save it to their local filters.
        • 
     
      • Saved in your browser. Your current filter is kept automatically. Local filters (Import tab) stay in this browser only. For a backup or another device, use Copy filter code.
        • 
    
      
  
      Keyboard shortcuts
      
    
        
     
      • Ctrl+Z undo the last change.
        • 
     
      • Ctrl+D duplicate the selected rule (Advanced Mode, Editor tab).
        • 
     
      • Alt+Up / Alt+Down select the previous or next rule (Advanced Mode, Editor tab).
        • 
     
      • Alt+Shift+Up / Alt+Shift+Down move the focused rule up or down in the list (Advanced Mode).
        • 
     
      • Esc close a help popover, or clear the rule search.
        • 
     
      • Tab to a ? button to read its help. Hover, focus or click/tap opens it.
        • 
     
      • Left / Right arrow move between the tabs when a tab is focused.

      About Oathfilter
      
    
      What it is
      
    
        
     
      • A free, unofficial fan tool for Broken Oath. It has no connection to Crater Studios.
        • 
     
      • Names and game data belong to their owners.
      
    
      Open source
      
    
        
     
      • The code is under the GPL-3.0, on GitHub. Game content is not covered by it.
        • 
     
      • Found a bug or have an idea? Open an issue on GitHub.
        • 
     
      • No warranty, provided as it is. Check every filter in the game.
      
    
      Planned: archetype modules, for example Caster Cold, Caster Lightning, Melee Physical, Melee Cold and Bow Physical.
      
  
      Privacy & technical
      
    
        
     
      • Runs in your browser. Your filter stays on your device unless you press "Share" in the Editor.
        • 
     
      • Your filter is saved only in local storage.
        • 
     
      • No cookies, no tracking, no accounts.
        • 
     
      • Share links: "Create link" uploads your game code and rule names (no personal data) to a small service on Cloudflare (Workers and D1), which stores them and returns a short link. Anyone with the link can open it, and the stored data cannot be deleted by you. Opening a link loads it from the same service. Cloudflare may log requests, for example your IP address. If the service is down, an offline link is created that contains the filter itself and uploads nothing.
        • 
     
      • The fonts (Cinzel, Barlow) are built into the page.
        • 
     
      • Hosted on GitHub Pages. GitHub may log visits, for example your IP address. The operator cannot see these logs.
        • 
     
      • Every 5 minutes the page checks a small file (version.json) for a new version. No filter data is sent by this check.

      Real vs. guessed
      
    
      Real
      
    
      • BOFILTER 1 code format.
      • Rule order: the first match wins.
      • Limit of 40 rules (tested in the game).
      • The five game presets.
      • Bases, levels and tags; affix groups; unique names and bases (public API).
      
    
      From game files
      
    
      • MORE options and their keys (read from exported codes).
      • Lists of bases, named reds and named lines.
      • Item level of each affix tier.
      
    
      Drop Test samples
      
    
      • Sample items are made up on purpose: they cover many rarities, bases and tiers to exercise your rules.
      • Drop rates are not simulated and not tested. The Drop Test checks rule matching and order only.
      • Mods per item and tier rolls are varied for coverage. They are not the game’s roll logic.
      
    
      Guessed
      
    
      • Which affix belongs to which line group; what counts as a good or top roll.
      • Uniques: their mods are ignored by line rules.
      • How a Gems rule reads.
      • Random sample flags: core-touched, 4+ sockets, truesworn, rune base, grade, required level, unsworn, chase red, sample runes.
      • Left out: bases that never drop at random (core-touched, ashen, gnome-made) and uniques with drop weight 0.
      
    
      Not checked
      
    
      • Whether newer builds changed the code format. The developer file loot_filter.md is older than the game: it still says 12 rules, while the game takes 40.
      • How the Sell action behaves in the game (items on the ground, uniques).
      • If a game export does not load, please report it on GitHub.
