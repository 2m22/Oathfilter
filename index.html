    What the game filter can do
    
    
      
     
    • Rules: up to 40. The top matching rule wins. If no rule matches, the item is shown.
      • 
     
    • Each rule checks: one item type, one rarity group, one of eight item level steps, one line group, a roll quality (any, good, top) and how many matching lines (1, 2+, 3+).
      • 
     
    • Actions: hide, show, highlight, highlight with light beam.
      • 
     
    • Look: eight highlight colours and a sound (silent, auto or one of four).
      • 
     
    • Never hidden: uniques, runes, Dwarven Runes, idols, the Cube, gems, currency, gold and flasks.
      • 
     
    • Game presets: All loot, Tidy, Strict, Very strict and End Game. Choose one at the top, then change it as you like.
    
  
    Good to know
    
    
      
     
    • A rule uses one line group. For two groups, use two rules.
      • 
     
    • The drop test is a best guess: which affixes belong to which line group, and what counts as a good or top roll, has not been checked in the game.
      • 
     
    • The limit of 40 rules comes from a test in the game. The sound and colour names come from the community Broken Oath Builder.
      • 
     
    • This page writes the plain BOFILTER 1 code. Options set in the game's MORE window are kept as they are.
